# Captures d'écran de BioSpace

Ce dossier contient les captures authentiques de l'application destinées à illustrer le projet dans le dépôt et lors de la présentation.

## Captures à ajouter

Enregistrer ici des captures prises directement dans l'application exécutée localement, sans données personnelles réelles :

1. `01-dashboard.png` — vue d'ensemble et état de santé d'un profil de démonstration ;
2. `02-daily-checkin.png` — formulaire du bilan quotidien ;
3. `03-alerts-actions.png` — alerte expliquée et suivi des actions ;
4. `04-trends.png` — tendances des indicateurs ;
5. `05-medical-report.png` — aperçu de la page de rapport ;
6. `06-validation.png` — résultats de validation sur missions simulées ;
7. `07-nasa-data.png` — consultation des études NASA OSDR.

## Règles

- Capturer l'interface réelle de BioSpace ; ne pas fabriquer une capture ou présenter une maquette comme une application fonctionnelle.
- Utiliser exclusivement des profils et données de démonstration.
- Masquer tout nom, identifiant, résultat ou autre donnée personnelle.
- Préférer le format PNG et une résolution lisible.
- Vérifier que chaque capture correspond à la version du code publiée sur la branche `main`.

Les fichiers image seront ajoutés dans ce dossier au fur et à mesure de la vérification de l'application.
